# 撰写公司内部通知

## 标题规范

必须在通知标题中加入部门名称，格式为「部门名称 + 关于 + 事项 + 通知」。

正确示例：
- 财务部关于2026年度预算编制事项通知
- 办公室关于调整作息时间事项通知

错误示例：
- 关于2026年度预算编制事项的通知（缺部门名称）
- 关于调整作息时间的通知（缺部门名称）

## 落款规范

通知落款处，在部门名称下面必须增加起草人的姓名。格式：

```
财务部
起草人：张三
2026年10月30日
```

## 起草人姓名未知时

如果不清楚起草人姓名，**必须先询问用户**，获得确切信息后才能起草。
不允许留空，也不允许编造姓名。
