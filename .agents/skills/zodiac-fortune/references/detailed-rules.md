# 星座运势详细规则

## 上升星座的影响

上升星座决定外在表现和第一印象。解读时：
- 太阳星座看内在动机和核心性格
- 上升星座看待人接物的方式和给人的第一印象
- 两者冲突时，优先按太阳星座给结论，用上升星座补充说明

## 月亮星座的影响

月亮星座反映情绪模式和安全感来源。解读感情部分时：
- 月亮星座说明在亲密关系里的真实需求
- 情绪波动大的日子，提示用户多给自己留缓冲时间
